# Editions: Free and Pro
{: .no_toc }

mobiCut comes in two editions. Both are the same app; Pro unlocks a few extras.

## Free is free forever, and ad-free forever

{: .important }
> **The Free edition will always be free, and it will always be free of ads.**
> No ads in Free, none in Pro, never: not now, not after the Play Store launch, not ever.
> Free is a complete video editor, not a trial. There's no time limit and no nagging.

## What each edition includes

| | Free | Pro |
|---|---|---|
| Price | **free, forever** | paid (see [Pro pricing](#pro-pricing)) |
| Ads | **none, never** | **none, never** |
| Split, delete, restore, undo | ✓ | ✓ |
| Speed 0.25×–16× per segment | ✓ | ✓ |
| Subtitles (burned in or .srt; position, fonts, colours, animation) | ✓ | ✓ |
| Mute a segment | ✓ | ✓ |
| Pictures, with zoom and slide effects | ✓ | ✓ |
| Soundtracks (mix or replace, fades) | ✓ | ✓ |
| Videos per project | **one** | **several**, edited as one |
| Export to the gallery | ✓ | ✓ |
| Length of the source video | **up to 1 hour** | no limit |
| Transitions | **Fade out-in**, fade in/out at start and end | all, including **Interleave** (crossfade) |
| Logo in the exported video | **small (mc) mobiCut logo, top right** | none |

## The Free edition's limits

These are the only differences. Everything else works the same in Free.

- **Source videos up to 1 hour.** The video you start a project from can be at most 60 minutes
  long. A shorter cut of a longer flight needs Pro.
- **A small (mc) mobiCut logo** in the top right corner of every exported video. It also shows in
  the preview, so what you see is what you get.
- **One video per project.** Pictures and soundtracks are free; adding more videos to a project
  is Pro.
- **Fade out-in is the only transition.** Fades between segments and fade in/out at the start and
  end are included; the **Interleave** crossfade is Pro.

In the app, Pro-only features carry an orange **PRO** badge. In Free they stay visible but
locked; tapping one tells you what it does.

## Try Pro now, in test builds

While mobiCut is in testing, **every Pro feature can be switched on for free**.
Test builds are the APKs from the [installation page]({{ "/installation/" | relative_url }}).

1. On the start screen, tap **⚙ Settings**.
2. Under **Test build: edition**, tap **Pro** (marker 1). Tap **Free** to see the app as Free
   users will.

{% include screen.html name="settings-edition" alt="The Settings sheet with Edition: PRO and the Test build: edition switch set to Pro, with the Privacy policy link and the app version below." %}

Test builds start in **Pro**. The switch only exists in test builds; the Play Store version won't
have it.

{: .note }
> Switching to Free never deletes anything. If a project uses Pro features (for example
> Interleave transitions), they stay saved and come back when you switch to Pro again.

## Pro pricing

{: .warning }
> Once mobiCut is on Google Play, **Pro will be paid**. The test switch goes away, and Pro is
> bought through Google Play. Prices aren't set yet.

The plan is three ways to get Pro, so you can pick what fits how often you edit:

| Option | For whom |
|---|---|
| **Subscription** (yearly, renews automatically) | You edit regularly through the season |
| **Short monthly pass** (one month, doesn't renew) | You edit occasionally, say after a holiday or a competition |
| **One-time purchase** | You'd rather pay once and keep Pro |

Whatever happens with Pro, the **Free edition stays free and without ads**.
