# Projects
{: .no_toc }

A project is one video plus everything you did to it. mobiCut saves projects automatically; the
start screen lists them, newest first.

1. TOC
{:toc}

---

{% include screen.html name="home" alt="Start screen with three recent projects, the Settings and New project buttons, and a project's ⋮ menu button." %}

1. **Settings**: edition and app version.
2. **New project**.
3. **A project**: thumbnail, length of the finished video, number of segments and subtitles,
   when it was last edited. Tap to open.
4. **⋮ menu**: rename or delete.

## Start a new project

1. Tap **New project**.
2. Choose where the video is:
   - **Gallery**: videos on this phone.
   - **Browse files**: an SD card, a USB camera or drive, Downloads, Google Drive and other
     file providers. Use this for action cameras plugged in by USB.
3. Pick the video. The editor opens with the whole video as one segment.

{: .note }
> In the **Free** edition the source video can be **up to 1 hour** long. Longer videos need Pro.

{% include screen.html name="new-project" alt="The 'New project from…' sheet with Gallery and Browse files." %}

{: .tip }
You can also start from another app: in the gallery, **Share** a video and choose **MobiCut**.

## Open a project

Tap it on the start screen. You land where you left off. Press **←** (or the phone's back
gesture) to return to the list; nothing needs saving.

## Rename a project

New projects are named after the video file. To rename:

- on the start screen, tap **⋮ → Rename**, or
- in the editor, tap the project name at the top.

Type the new name and tap **Rename**.

{% include screen.html name="project-menu" alt="The ⋮ menu of a project with Rename and Delete." %}
{% include screen.html name="rename-project" alt="The Rename project dialog with the current name selected." %}

## Delete a project

Tap **⋮ → Delete** and confirm. This removes only the project (your edits). **The original video
and anything you exported stay in your gallery.**

{% include screen.html name="delete-project" alt="The Delete project? confirmation." %}

## Where things are kept

| What | Where |
|---|---|
| Your edits | Inside the app. Removed if you uninstall mobiCut. |
| Original video | **Where it was.** mobiCut only links to it: it never copies, downloads or uploads it. |
| Exported videos | `Movies/MobiCut` (shows up in the gallery) |
| Subtitle files (.srt) | `Download/MobiCut` |

If the original video is moved or deleted, see [Missing video]({{ "/operations/missing-video/" | relative_url }}).
